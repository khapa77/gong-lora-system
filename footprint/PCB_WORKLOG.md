# Плата Gong LoRa — журнал решений и чек-лист (для продолжения)

> Состояние на 2026-09-27. Точка входа, чтобы продолжить работу над платой в
> новой сессии. ТЗ для разводки — [`PCB_SPEC_PROMPT.md`](PCB_SPEC_PROMPT.md).

---

## 1. Принятые решения

| Вопрос | Решение | Почему |
|---|---|---|
| Какая плата | **Универсальная плата узла**: одна плата под сервер и клиентов, под все ветки прошивки | LoRa + реле + кнопка + LED + DS3231 + аудио; разница только в прошивке и в том, что впаяно |
| ESP32 | **ESP32-DevKitC-V4 38 pin в гнёздах** | Прошивка по USB без извлечения, замена за минуту |
| LoRa-модуль | **Только Ra-02 (SX1278, 433 МГц)** в гнезде 2×4 | Прошивка уже отлажена на нём; место под E22 не закладываем |
| Meshtastic | **Не используем** | Задержка доставки через mesh от секунд до десятков секунд, протокол чатовый; для 500 м достаточно прямой связи |
| SX1262 / E22 | **Отложено до полевого теста** | Выигрыш по бюджету всего 2–4 dB. Реальный плюс E22 — TCXO для узкой BW 31.25 kHz (у Ra-02 кварц ±10–20 ppm, почти предел допустимого ухода ±7.8 кГц) |
| Питание | **HLK-10M05 (5 В / 2 А)**, 3.3 В через LD1117V33 | Потребление ~1.3 А пик, запас есть |
| Li-Po | Не нужен | — |
| Аудио | Модуль **MAX98357A** в гнезде 1×7, динамик 4 Ом 3 Вт на клеммник модуля | v1 |
| RTC | Модуль **DS3231 ZS-042** в гнезде | Нужен и серверу, и клиентам (автономное время) |
| Реле | **Внешний модуль реле 5 В с оптроном**, на плате только разъём JST-XH 3 pin (GPIO27) | 220 В коммутируется вне платы |
| Кнопка | **GPIO32** (перенесена с GPIO4), кнопка на плате + выносная | GPIO4 занят LoRa DIO0 |
| LED статуса | **GPIO13** | Как у клиента; GPIO2 — strapping-пин |
| Антенна | Штырь 1/4λ **17 см через SMA** уже есть | Нужна «земля» (полигон платы/радиалы), одинаковая поляризация, короткий кабель |
| Формат результата | **ТЗ-промпт** для другого ИИ/разводчика, доводка в KiCad или EasyEDA | Трассировку без DRC в тексте делать нельзя (220 В) |

## 2. Дальность: оценка радиоканала (500 м, улица + деревья + стены)

Текущие настройки LoRa-веток: **SF12 / BW 31.25 kHz / 17 dBm**, 433 МГц.

| Статья | dB |
|---|---|
| Бюджет (TX +17, чувствительность ≈ −142) | ≈ 159 |
| Потери в свободном пространстве, 500 м | −79 |
| Деревья | −3…−10 |
| Стена кирпич / ж/б (каждая) | −8…−15 / −15…−25 |
| Запас на замирания | −10…−15 |

Вывод: результат определяют **стены и размещение антенны**, а не чип. Антенна
у окна или снаружи даёт 20–40 dB, SX1262 — только 2–4 dB. Пакет на SF12/31.25
идёт по эфиру ~4 с — для команды «звони сейчас» с ACK это долго.
Регуляторика РФ: 433 МГц без лицензии — 10 мВт (10 dBm), сейчас стоит 17 dBm.

## 3. Найденные проблемы

| # | Проблема | Статус |
|---|---|---|
| P1 | **R3 1 МОм на SD MAX98357A лишний**: на breakout Adafruit уже есть 1 МОм SD→Vin (datasheet, стр. 10–11). Два параллельно дают ~0.83 В → **только правый канал** вместо (L+R)/2 | В ТЗ R3 = DNP. `schematic_netlist.md` **не исправлен** |
| P2 | **GPIO4 занят дважды**: кнопка в `standalone`, DIO0 в LoRa-ветках | В ТЗ кнопка на GPIO32. Прошивка **не изменена** |
| P3 | **Старый netlist в `standalone`**: неправильная нумерация DevKitC (5V/GND перепутаны). Исправление только в `lora-ds-autonomy` (d545d8c) | В ТЗ правильная распиновка. Файлы в `standalone` **не обновлены** |
| P4 | Вывод 3V3 DevKit параллельно выходу LD1117 (в старом netlist «опционально») | В ТЗ — NC, два LDO параллельно нельзя |
| P5 | USB DevKit при прошивке подаёт 5 В обратно на выход HLK | В ТЗ — диод SS34 + обходная перемычка 0 Ом (DNP) |
| P6 | Порядок пинов MAX98357A у клонов может отличаться от Adafruit; переходная плата Ra-02 2×4 и посадочное место HLK-10M05 не сверены с реальными деталями | Помечено «ПРОВЕРИТЬ» в ТЗ |

## 4. Инструменты для разводки

| Инструмент | Для чего |

| **Quilter** | ИИ-расстановка и трассировка проекта KiCad |

| **Freerouting** | Бесплатный автотрассировщик, плагин KiCad |
| **Авторазводка EasyEDA** | Для 2-слойной платы с модулями в гнёздах обычно хватает |
| **atopile / SKiDL** | Схема кодом → netlist KiCad |

Возможности и экспорт проверять на сайтах — всё быстро меняется.

## 5. Чек-лист — что дальше

### Прошивка
- [ ] `standalone`: `BUTTON_PIN 4 → 32`, `STATUS_LED_PIN 2 → 13` в `server/src/config.h`
- [ ] Проверить, что клиентская прошивка использует GPIO13 для LED и ничего на GPIO32/27
- [ ] Режим полевого теста LoRa: сервер шлёт ping раз в 5 с, клиент пишет RSSI/SNR/потери в Serial и мигает LED по качеству связи
- [ ] Решить мощность TX с учётом лимита 10 dBm

### Полевой тест (до заказа платы)
- [ ] Поставить узлы в реальные точки на 500 м, антенны вертикально
- [ ] Записать RSSI/SNR/потери в разное время суток и при разной температуре
- [ ] SNR > −10 dB и нет потерь → Ra-02 остаётся; провалы → рассмотреть E22-400M22S (TCXO)

### Документация в `footprint/`
- [ ] Исправить `schematic_netlist.md`: R3 → DNP (P1), распиновка DevKitC (P3), 3V3 DevKit → NC (P4)
- [ ] Перенести исправленные `gen_pcb.py` / `gen_schematic.py` / JSON из `lora-ds-autonomy` или пометить старые как устаревшие
- [ ] Добавить в netlist реле, кнопку, LED, D1, J6 — синхронизировать с ТЗ

### Сверка с реальными деталями
- [ ] Порядок пинов своего MAX98357A; есть ли на нём свой резистор 1 МОм на SD
- [ ] Пиноут и размеры переходной платы Ra-02 2×4
- [ ] Datasheet и посадочное место купленной ревизии HLK-10M05
- [ ] Диаметр и шаг электролитов, держатель предохранителя, клеммник

### Разводка
- [ ] Отдать `PCB_SPEC_PROMPT.md` в Flux.ai / другой ИИ или собрать схему в KiCad
- [ ] Расставить модули по зонам (220 В / цифра+RF / аудио)
- [ ] Трассировка (Quilter / Freerouting / EasyEDA) + DRC
- [ ] Проверить изоляцию 220 В: ≥ 6.4 мм + прорезь между первичкой и вторичкой
- [ ] Прогнать чек-лист §10 ТЗ, заказать 5 шт. на JLCPCB

### Сборка
- [ ] Не включать Ra-02 без подключённой антенны
- [ ] DS3231 ZS-042: для CR2032 выпаять зарядный резистор или ставить LIR2032
- [ ] Запаять R11 **или** R12 под полярность модуля реле
