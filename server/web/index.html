Все дни курса одним файлом. «Скачать» — резервная копия или заготовка для правки и для других гонгов. В файле одинаковые дни описаны один раз в templates, а days — список шаблонов по дням (вместо имени можно вписать день целиком). Загрузка заменяет расписание всех дней сразу; текущий день курса не меняется. Если связь оборвётся посередине, старый курс останется как был.

Clock

Источник выбирается сам: 🌐 NTP, если устройство подключено к сети с интернетом (вкладка WiFi), иначе 🔋 DS3231 (батарейка CR2032). Каждая синхронизация по интернету сразу записывается в DS3231.

Ручная установка (UTC+3) — только если нет ни интернета, ни DS3231 с верным временем; при появлении интернета NTP её перезапишет. Дата важна не только для расписания дня, но и для перехода расписания на следующий день курса — проверьте её при первой настройке.

Device

Номер входит в имя Wi-Fi сети и адрес: GongServer-N, http://gongN.local. Без номера имя берётся из MAC. После смены номера устройство перезагрузится, а телефон нужно заново подключить к сети с новым именем (пароль тот же). Подпись видна только здесь, в шапке и вкладке браузера.

Security
Web admin is open — anyone on the network can access it.

Login: admin / your password. Stored on device, cleared with "Disable Auth" — or, if the password is forgotten, by typing reset-auth in the USB serial monitor (115200).

Gong
WiFi

Точка доступа GongServer-N (192.168.4.1) работает всегда — через неё можно зайти, даже если сеть недоступна. При подключении к роутеру AP переходит на его канал: телефон может на секунду отключиться от GongServer. В сети роутера устройство доступно по адресу http://gongN.local (N — номер, карточка Device) или по IP из статуса.
