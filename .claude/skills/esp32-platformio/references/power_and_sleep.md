# Энергопотребление и режимы сна

## Режимы

| Режим | Потребление (примерно) | Что сохраняется | Пробуждение |
|---|---|---|---|
| Active (Wi-Fi TX) | ~160-260 мА (пики выше) | всё | — |
| Active (без радио) | ~20-40 мА | всё | — |
| Modem sleep | ~3-20 мА | RAM, CPU работает | автоматически, радио засыпает между пакетами |
| Light sleep | ~0.8 мА | RAM, состояние | таймер, GPIO, UART |
| Deep sleep | ~10 мкА | только RTC-память | таймер, GPIO (EXT0/EXT1), touch, ULP |

Цифры ориентировочные и сильно зависят от конкретного модуля/платы — не выдавай их как гарантированные без пометки "примерно".

## Deep sleep — пробуждение по таймеру

```cpp
#include <esp_sleep.h>

void setup() {
  esp_sleep_enable_timer_wakeup(60 * 1000000ULL); // микросекунды, тут 60 сек
  esp_deep_sleep_start();
}
```
После deep sleep выполнение начинается заново с `setup()` — обычные переменные не сохраняются. Для сохранения данных между циклами сна используй `RTC_DATA_ATTR`:

```cpp
RTC_DATA_ATTR int bootCount = 0;

void setup() {
  bootCount++;
}
```

## Deep sleep — пробуждение по GPIO

```cpp
esp_sleep_enable_ext0_wakeup(GPIO_NUM_33, 1); // пробуждение при HIGH на GPIO33
```
`ext0` — один пин, `ext1` — несколько пинов (маска), с выбором ANY_HIGH/ALL_LOW. Для ext0/ext1 на классическом ESP32 годятся только RTC GPIO (обычно 0, 2, 4, 12-15, 25-27, 32-39) — сверяйся с datasheet платы.

## Практические советы по снижению потребления

- Отключай периферию явно перед сном, если она не нужна (`WiFi.disconnect(true); WiFi.mode(WIFI_OFF);`).
- Понижай частоту CPU (`setCpuFrequencyMhz(80)`), если максимальная производительность не нужна — заметно снижает ток в active-режиме.
- При питании от батареи — учитывай пиковый ток при Wi-Fi TX (может доходить до 300-500 мА короткими импульсами): дешёвые линейные регуляторы или тонкие батарейные дорожки могут давать просадку напряжения и спонтанные перезагрузки. Это частая причина "плата рандомно ребутится при подключении к Wi-Fi" — см. также `references/hardware.md`.
