# Периферия ESP32 (GPIO, ADC, PWM, I2C, SPI, UART)

## GPIO — ловушки, о которых нужно предупреждать

**Strapping pins (классический ESP32)** — влияют на режим загрузки, использовать с осторожностью:
- GPIO0 — должен быть HIGH при старте (LOW = режим прошивки)
- GPIO2 — должен быть LOW или floating при старте
- GPIO12 (MTDI) — должен быть LOW при старте (HIGH может выбрать неверное напряжение флеша и повредить модуль)
- GPIO15 (MTDO) — должен быть HIGH при старте

**Input-only пины:** GPIO34, 35, 36 (VP), 39 (VN) — нет подтяжек, нет output, только вход. Часто используются для ADC/кнопок с внешней подтяжкой.

**На ESP32-S3/C3** нумерация и ограничения другие — сверяйся с datasheet конкретной платы, не переноси автоматически ограничения классического ESP32.

Пример базового кода:
```cpp
void setup() {
  pinMode(2, OUTPUT);
  digitalWrite(2, HIGH);
}
```

## ADC

- **ADC1**: GPIO32–39, работает всегда, в том числе с активным Wi-Fi
- **ADC2**: GPIO0, 2, 4, 12–15, 25–27 — **конфликтует с Wi-Fi** (радио использует те же ресурсы). Если Wi-Fi включён, ADC2 может давать нестабильные показания или зависать. Предупреждай об этом явно, если пользователь использует Wi-Fi + ADC2.
- Разрешение по умолчанию 12 бит (0–4095), референсное напряжение нелинейно у краёв диапазона — для точных измерений рекомендуй калибровку через `esp_adc_cal` (ESP-IDF) или использование библиотеки с встроенной калибровкой.

```cpp
int raw = analogRead(34); // ADC1, безопасно с Wi-Fi
float voltage = raw * (3.3 / 4095.0);
```

## PWM (LEDC)

Arduino-обёртка использует блок LEDC ESP32 (не "software PWM"):

```cpp
const int pwmPin = 18;
const int freq = 5000;
const int channel = 0;
const int resolution = 8; // бит

void setup() {
  ledcSetup(channel, freq, resolution);
  ledcAttachPin(pwmPin, channel);
}

void loop() {
  ledcWrite(channel, 128); // 50% duty на 8 бит
}
```
Каналов LEDC ограниченное число (обычно 16, по 8 high-speed + 8 low-speed на классическом ESP32) — если пользователь просит много ШИМ-выходов, посчитай лимит для его платы.

## I2C

```cpp
#include <Wire.h>

void setup() {
  Wire.begin(21, 22); // SDA, SCL — дефолтные пины ESP32 (можно менять программно)
  Wire.beginTransmission(0x3C);
  Wire.write(0x00);
  Wire.endTransmission();
}
```
- Нужны подтяжки (обычно 4.7кОм) на SDA/SCL, если на модуле датчика их нет.
- ESP32 поддерживает несколько I2C-шин (`Wire`, `Wire1`) — полезно при конфликте адресов устройств.
- При "зависании" шины (частая проблема) — проверяй адрес устройства сканером I2C и убедись, что нет плавающих линий.

## SPI

```cpp
#include <SPI.h>

void setup() {
  SPI.begin(18, 19, 23, 5); // SCK, MISO, MOSI, SS
  pinMode(5, OUTPUT);
  digitalWrite(5, HIGH);
}
```
- Классический ESP32 имеет несколько SPI-контроллеров (VSPI/HSPI), можно использовать параллельно для разных устройств.
- При работе с SD-картами и дисплеем одновременно — следи за конфликтом CS-линий и общей пропускной способностью шины.

## UART

- ESP32 имеет 3 аппаратных UART (UART0 обычно занят USB/прошивкой и `Serial.print`).
- Для второго устройства используй `Serial1`/`Serial2` с явным указанием пинов:

```cpp
Serial2.begin(9600, SERIAL_8N1, 16, 17); // RX, TX
```
