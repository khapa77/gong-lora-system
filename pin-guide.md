# Pin-to-pin подключение Ra-02 (SX1278) к ESP32 на макетной плате

Без паек — только прямые соединения и необходимые pull-up резисторы.

## Общие пины для сервера и клиента (Ra-02 / SX1278)

| SX1278 (Ra-02) | ESP32   | Примечание |
|---------------|---------|------------|
| VCC           | 3.3V    | 100–220 µF + 100 nF рядом с VCC/GND |
| GND           | GND     | |
| NSS           | GPIO5   | pull-up 10 kΩ → 3.3V (иначе слушает SPI-мусор во время загрузки ESP32) |
| RST           | GPIO14  | pull-up 10 kΩ → 3.3V + 100 nF → GND (длинные провода) |
| DIO0          | GPIO4   | **Не GPIO2!** Если провод на GPIO2 — SPI инициализируется, пакеты физически приходят, но прерывание никогда не сработает без ошибок в логе. |
| SCK           | GPIO18  | Стандартный VSPI |
| MISO          | GPIO19  | Стандартный VSPI |
| MOSI          | GPIO23  | Стандартный VSPI |

## MAX98357A (I2S-усилитель, только сервер/клиент)

| MAX98357A | ESP32   | Примечание |
|-----------|---------|------------|
| BCLK      | GPIO26  | I2S |
| LRC       | GPIO25  | I2S |
| DOUT      | GPIO33  | На части плат GPIO32/33 заняты внешним кварцем 32.768 кГц — проверить ревизию. |
| SD        | 1 MΩ к VDD | Иначе режим «только левый канал» вместо (L+R)/2. |
| GAIN      | NC      | 9 дБ. Зафиксировать письменно вне зависимости от значения. |

## DS3231 RTC (только сервер, обязателен)

| DS3231 | ESP32 |
|--------|-------|
| SDA    | GPIO21 |
| SCL    | GPIO22 |

## Статусный LED клиента (опционально)

| LED          | ESP32    | Примечание |
|--------------|----------|------------|
| Анод         | GPIO13   | Через резистор 220–330 Ω |
| Катод        | GND      | Можно отключить задав `-1` в `config.h` |

## Ключевые замечания

1. **Питание Ra-02**: отдельный стабилизатор/источник 5V → 3.3V с ферритовой развязкой (FB1). При максимальной громкости ESP32 brownout-нется.
2. **NSS pull-up + RST pull-up + RC + DIO0 на GPIO4** — три самых частых «тихих» бага.
3. **DIO0 и NSS** лучше не длинными проводами страдать — на расстоянии > 10 см без pull-up работать не будет.
4. **17 дБм TX Power** превышает лимит ISM 433 МГц в EU/РФ (~5×).
5. **SF12/BW31.25** — airtime кадра в секундах. Не подавать питание на модуль без антенны.
