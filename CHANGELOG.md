# Изменения — ветка `standalone-max`

## 6.2-max — октябрь 2026

Ответвление от `standalone` (всё из раздела «Не выпущено» ниже, кроме реле,
светодиода, кнопки и PCM5102A).

- **MAX98357A вместо PCM5102A** на тех же пинах I2S (26/25/33): усилитель
  3 Вт прямо на динамик, внешний усилитель не нужен. Моно-сведение
  (`forceMono`) оставлено — звук полный при любом выборе канала резистором SD.
- **Реле удалено**: нет прогрева и предвключения, гонг звучит сразу. Удалены
  карточка реле в вебе, `/api/relay`, `relay_on` в `/api/status`, флаги
  `RELAY_*`. Настройки реле в NVS после перехода с `standalone` не используются.
- **Светодиод удалён** (GPIO13 свободен). Состояние — только красная плашка в
  веб-интерфейсе.
- **Кнопка удалена** (GPIO32 свободен): управление только через веб-интерфейс по Wi-Fi.
  Сброс забытого пароля админки — командой `reset-auth` в Serial по USB
  (`AUTH_RESET_CMD`), вместо удержания кнопки при включении.
- Страницы `/info` и `/guide`, Instruction, Testing_table переписаны под эту сборку.
- **Номер и подпись устройства** (карточка Device, `/api/device`, NVS `device`):
  Wi-Fi `GongServer-N`, адрес `http://gongN.local`, в шапке веба и во вкладке
  `#N · подпись`. Пока номер не задан — имя из MAC (`GongServer-A3F2`) и предупреждение
  в вебе. Смена номера перезагружает устройство. Номер для партии: `-DDEVICE_NUM=N`.
- **Потолок громкости `VOLUME_LIMIT`** (`config.h`, по умолчанию **25**): громкость 30
  звучит на −3.5 дБ, вся шкала 0–30 масштабируется. Пиковый ток MAX98357A падает
  вдвое — хватает HLK-PM01. Полная громкость: `-DVOLUME_LIMIT=30`. Расчёт — `docs/power.md`.

# Изменения — ветка `standalone`

## Не выпущено

Реле
- **Предвключение**: гонг по расписанию включает реле за *Warm-up* до своего
  времени, звук начинается точно по расписанию (раньше сдвигался на прогрев).
  Play в вебе / кнопка — как раньше, звук ждёт прогрева; если реле уже включено,
  ждёт только остаток. Гонг раньше *Warm-up* после 00:00 предвключения не получает.
- Предел *Warm-up* — **30 с** (был 5 с).
- По умолчанию реле включается **низким уровнем** (`-DRELAY_ACTIVE_LOW=1` в `platformio.ini`),
  под модули с оптроном. Подтяжка входа реле — к 3.3 В. Модуль с активным HIGH —
  закомментировать строку.

Веб
- Страница **`/info`** — схема подключения (ESP32, PCM5102A, DS3231, кнопка, реле,
  светодиод) с номерами пинов DevKit, встроена в прошивку; ссылка «Схема» в шапке.
- Страница **`/guide`** — краткая инструкция: как всё устроено, светодиод, кнопка,
  реле, предупреждения, время, дни курса, пароли, неисправности; ссылка «Инструкция» в шапке.
- Instruction §8–9: Always OFF больше не обещает «встроенный динамик»; подсказки
  светодиода при удержании кнопки.

Звук
- **PCM5102A вместо MAX98357A** на тех же пинах I2S (26/25/33). Прошивка сводит
  каналы в моно (`audio.forceMono(true)`): PCM5102A выдаёт L и R раздельно, а
  MAX98357A смешивал их резистором на SD. Выход линейный — нужен внешний усилитель;
  подключение и перемычки модуля — README §2.3a, Instruction §1.

Кнопка
- Удержание **больше 8 с** в тишине — реле вкл/выкл **без гонга** (только в режиме Auto).
  Включённое кнопкой реле само выключается через 30 мин, после перезагрузки выключено;
  в UI — `button, N min left`.
- Гонг с кнопки теперь звучит **при отпускании** после 3 с (раньше — на 3-й секунде,
  пока кнопка зажата). Пока держите: светодиод горит — будет гонг, мигает — реле.

Железо (плата узла v1, `footprint/`)
- Кнопка перенесена с GPIO4 на **GPIO32**, светодиод состояния — с GPIO2 на **GPIO13**,
  как на печатной плате. На макете: кнопку перекинуть на GPIO32; встроенный
  синий LED DevKit вернуть можно через `-DSTATUS_LED_PIN=2`.
- Netlist, BOM и генераторы схемы и платы приведены к ТЗ `PCB_SPEC_PROMPT.md`.

## 6.2-solo — сентябрь 2026

Исправления по аудиту ([Audit_6.2.md](Audit_6.2.md)).

**Обновление с 6.0/6.1: сначала только `pio run -t upload`, без `uploadfs`**
— при первой загрузке настройки переносятся в NVS ([Instruction.md §4](Instruction.md#4-обновление-с-предыдущей-версии)).

Расписание
- Нехватка памяти больше не стирает расписание при сохранении.
- Догоняющий гонг после перезагрузки работает независимо от того, когда был предыдущий.
- Файл активного дня — единственная копия расписания; активный день и дата — в NVS.
- Смена дня проверяется каждую секунду; гонг в 00:00 берётся из нового дня.
- Нечитаемые шаблоны не перезаписываются; ошибка загрузки видна на светодиоде и в UI.
- Проверка ввода: обязательные `hour`/`min`, диапазоны, описание ≤ 96 байт,
  повторы ≤ 7 (и в `/api/play`), трек должен существовать; пропавший трек заменяется треком 1.

Надёжность
- Расписание, кнопка, реле, время, Wi-Fi работают в отдельной задаче — веб-клиенты им не мешают.
- Флеш не форматируется при ошибке монтирования; прошивка работает без ФС и сообщает об этом.
- Светодиод состояния (GPIO2), красная плашка предупреждений, причина сброса и счётчик сбоев.

Безопасность
- Пароль админки, Wi-Fi, реле — в NVS.
- Кэш проверки пароля, торможение перебора, минимум 8 символов.
- Проверка `Host` против DNS rebinding.
- Сброс пароля кнопкой: 10 с при включении.

Реле: прогрев ≤ 5 с, удержание после гонга ≤ 20 с.

Веб-интерфейс вшит в прошивку — для обновления UI хватает `upload`.

## 6.1-solo — сентябрь 2026

- Время: NTP при наличии интернета → DS3231 → вручную, выбор автоматический.
- Часовой пояс `TIME_TZ` (`MSK-3`), DS3231 хранит UTC (однократная миграция).
- Проверка показаний DS3231; проверка числа дней в месяце при ручной установке.
- Тайминги реле из файла проверяются при загрузке.

## 6.0-solo — сентябрь 2026

- Одиночная версия без LoRa: реле внешнего усилителя (GPIO27), подключение к Wi-Fi роутера (STA).
- Физическая кнопка на GPIO4: 3 с — гонг, 1 с — стоп.
- Веб-интерфейс отдаётся несжатым (исправлены «иероглифы» на телефонах).
